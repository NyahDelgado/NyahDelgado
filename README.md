# 🖥️ 01 — PRESENTATION DESIGN

## 📌 Principles

> Good presentation design communicates information clearly,
> effectively, and visually.

### Key Points

- 🎯 Know your audience
- 📐 Use consistent layouts
- 🔤 Choose readable typography
- 🎨 Use an appropriate color palette
- 🖼️ Use visuals effectively
- 📊 Avoid overcrowding slides
- ✨ Maintain visual consistency
